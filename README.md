# QuoteBox · 网页文字图片收藏盒

一个纯本地的 Chrome 扩展：在网页上选中文字或图片，一键保存成卡片，支持保留格式、管理、搜索和导入导出。所有数据只存在浏览器本地 IndexedDB，不经过任何服务器。

## 功能

- 选中文字 / 图片 / 链接，右键菜单或弹窗一键收藏
- 保留原文格式（标题、段落、链接、图片）
- 收藏管理页：搜索、编辑、删除、批量导出
- 全量导入 / 导出 JSON，方便备份和迁移
- 完全离线，无账号、无网络请求

## 安装（开发者模式）

1. 下载或克隆本仓库
2. 打开 `chrome://extensions/`
3. 右上角开启「开发者模式」
4. 点击「加载已解压的扩展程序」，选择仓库根目录
5. 在任意网页选中内容，点击扩展图标或右键「保存选中内容到 QuoteBox」

也可以在扩展卡片上点「固定」，把图标常驻工具栏。

## 使用

- **保存**：选中文字/图片后点弹窗里的「保存选中内容」，或使用右键菜单
- **管理**：弹窗右上角房子图标打开管理页，可搜索、编辑、删除
- **备份**：弹窗底部「导出全部」生成 JSON；换设备后用「导入」恢复

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存卡片数据 |
| `contextMenus` | 右键菜单入口 |
| `activeTab` / `scripting` | 读取当前页面选中的内容 |
| `downloads` | 导出备份文件 |
| `<all_urls>` | 在任意网页上都能收藏 |

扩展不发送任何数据到外部服务，也不读取与收藏无关的页面内容。

## 目录结构

```
manifest.json     扩展清单（MV3）
background.js     后台 Service Worker，IndexedDB 唯一写入方
content.js        页面内容捕获
db.js             IndexedDB 封装
popup.html/js/css 工具栏弹窗
manager.html/js/css 收藏管理页
```

## 已知限制

- 只支持 Chromium 内核浏览器（Chrome / Edge）
- 图片以 Data URL 存入 IndexedDB，收藏大量高清图会占用较多本地空间
- 暂未提供云同步

## 开发

无需构建工具，修改文件后在 `chrome://extensions/` 点扩展卡片上的刷新按钮即可。
